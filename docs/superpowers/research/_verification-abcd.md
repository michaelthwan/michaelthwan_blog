This is the identical class of design problem the dataset itself correctly recognizes and downgrades to Tier D for the `smoking` edges (justified explicitly: "no RCT evidence exists for smoking exposure... not ethical"). The dataset applies the correct "cannot randomize this exposure -> downgrade tier" logic to the `smoking` edges elsewhere in scope but not here. Likely should be Tier C or D. Evidence: PubMed abstract methods text, PMID 37705506 (quoted in section 4 above).

Per the criteria (C = prospective cohort, D = cross-sectional/case-control), this should be Tier D — the same logic the dataset correctly applies to the sibling `smoking -> hs_crp_il6` edge (also case-control, also tagged D). Inconsistent tiering for the same behavior within the same dataset. Evidence: PubMed abstract, PMID 36926662 (section 12/13 above).

3. **[LOW] Mislabeled subgroup — smoking -> hs_crp_il6, DOI 10.1016/j.ijcrp.2026.200695.** The `effect` field calls the pooled all-smokers hsCRP statistic (0.05 [0.04,0.06], 27 studies) "current smokers vs non-smokers," but the true current-smoker-only value in the same paper's Table 2 is 0.06 (0.05, 0.07) from 34 studies — a different number. Evidence: PMC13476467 full-text Table 2 (section 5 above).

The full sentence is present in the same PubMed abstract already used for the rest of the edge. No fact is wrong, but the excuse for the incomplete quote is false. Evidence: PMID 41156531 abstract (section 10 above).

5. **[LOW] Quote reconstruction, not a genuine single-source copy — curcumin_piperine -> hs_crp_il6 (IL-6 edge), DOI 10.1002/fsn3.70588.** `verbatim` splices an abstract sentence fragment with unit/CI values that only appear in a separate table. All values are accurate; the presentation as one continuous quote is not accurate. Evidence: PMC12257354 (section 7/8 above).

## Criteria verdicts (across the 15 edges checked live)

1. **evidence_tier matches real study design** — **FAIL** (2 confirmed defects: #1 and #2 above; 13 of 15 checked edges were correct). The specific failure pattern is that the "cannot ethically randomize this exposure -> lower tier" rule, which the dataset applies correctly in some places (the `smoking -> hs_crp_il6` edge), is not applied consistently to other exposure behaviors with the same property (chronic alcohol use, and smoking again in the triglycerides edge).
2. **direction correct including sign** — **PASS** (15/15 checked edges had correct direction, including several null/no-effect edges verified as genuinely null in the source).
3. **conditional_on does not overstate generality** — **PASS** (15/15 checked edges correctly scoped their population restrictions — e.g., alcohol edge correctly restricts to "healthy men, chronic use," the magnesium edge correctly notes ISI-not-PSQI and does not overclaim, the sleep-restriction edge correctly frames itself as a single-night acute effect).
4. **paper.doi resolves and belongs to the paper named in paper.title** — **PASS** (15/15; every DOI resolved via NCBI eutils to a PubMed record whose title matched the edge's `paper.title` field, in some cases exactly, in others with trivial capitalization/punctuation differences only).
5. **verbatim is genuinely copied text, not paraphrase/reconstruction** — **PASS with 1 exception** (14/15 verbatim quotes were confirmed as genuine copies, in several cases from full-text tables rather than the abstract, which is acceptable; 1 edge — curcumin_piperine IL-6 — spliced text from two different source locations into what reads as one continuous quote).

## Single most important fix

**Apply the "exposure cannot be randomized -> this is not an RCT meta-analysis, downgrade the tier" rule consistently.** The dataset already contains the correct version of this reasoning (used explicitly for the `smoking -> hs_crp_il6` edge, whose caveats state "no RCT evidence exists for smoking exposure (not ethical), so this is necessarily observational/case-control evidence"). The same logic was not applied to the `alcohol -> serum_testosterone` edge (chronic alcohol exposure, also not randomizable) or the `smoking -> triglycerides` edge (same exposure, same paper family, missed the second time). A single pass re-checking every Tier-A-tagged edge in the dataset for behaviors that cannot ethically be randomized (alcohol, smoking, and likely a few others outside this scope, e.g. long-term diet adherence in free-living populations) against its actual reported study design would fix the most consequential and most easily-repeated class of defect found here.
